## Arrays and Lists
Arrays are written as `string[]`.
Arrays have a fixed size after creation.
Lists are written as `List<string>`.
Lists can be resized using `Add()` and `Remove()`.
I learned about lists in OOP and PSP courses before. Although I was using Python at the time, the basics are the same. Therefore, I only spent 10 minutes on the `.add`, `.remove`, and `.insert` methods. I might have forgotten a bit about calculating the total length of all names, so I spent some time looking up the syntax.

### Syntax differences
The differences between Array (fixed size), List (resize), and insertion/deletion.
### Performance and flexibility
Array and List both support index access, but List can change size while Array cannot.
### When I would use each
Use Array when the size is fixed, and List when the quantity changes.
