# Topic 3 Prac A Reflection

Inheritance helped me avoid writing the same code again. The common properties and methods are in the BankAccount class. SavingsAccount and CheckingAccount can use these members.

SavingsAccount has a new responsibility to store the interest rate and apply interest to the balance. CheckingAccount has a transaction fee and removes the fee when money is withdrawn.

The base keyword sends the owner and balance values to BankAccount. The virtual and override methods allow each account type to display different information.
